# Customer Churn Prediction

## Project Overview

This project predicts whether a telecom customer is likely to churn using Machine Learning. The complete workflow includes data cleaning, exploratory data analysis (EDA), feature engineering, preprocessing, model training, and model evaluation.

---

## Dataset

- Dataset: IBM Telco Customer Churn Dataset
- Total Records: 7032
- Target Variable: Churn

---

## Workflow

- Data Cleaning
- Handling Missing Values
- Exploratory Data Analysis (EDA)
- Feature Encoding
- Feature Scaling
- Correlation Analysis
- Train-Test Split
- Machine Learning Model Training
- Model Evaluation

---

## Machine Learning Models Used

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- Gaussian Naive Bayes

---

## Model Performance

| Model | Accuracy |
|--------|----------|
| Logistic Regression | 78.68% |
| SVM | 78.11% |
| Random Forest | 77.68% |
| KNN | 75.55% |
| Decision Tree | 71.42% |
| Naive Bayes | 68.08% |

---

## Key Insights

- Customers with Month-to-Month contracts have the highest churn rate.
- Customers with shorter tenure are more likely to churn.
- Fiber Optic internet users show a higher churn rate.
- Customers without Online Security and Tech Support are more likely to churn.
- Contract type and tenure are among the most influential features.
