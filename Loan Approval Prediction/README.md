# Loan Approval Prediction

## Project Overview

This project predicts whether a loan application will be **Approved** or **Rejected** using Machine Learning algorithms.

The project follows a complete end-to-end Machine Learning workflow including data cleaning, exploratory data analysis, preprocessing, model building, and performance evaluation.

---

## Dataset

Source:
Loan Approval Prediction Dataset

Records: **4,269**

Target Variable:

- loan_status

Classes:

- Approved
- Rejected

---

## Workflow

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Numerical Feature Analysis
- Categorical Feature Analysis
- Outlier Detection
- Label Encoding
- Correlation Analysis
- Train-Test Split
- Feature Scaling
- Model Building
- Model Evaluation

---

## Models Used

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Gaussian Naive Bayes
- Decision Tree
- Random Forest

---

## Model Performance

| Model | Accuracy |
|--------|---------:|
| Random Forest | **98.01%** |
| Decision Tree | **97.78%** |
| Gaussian Naive Bayes | **93.68%** |
| Support Vector Machine | **92.39%** |
| Logistic Regression | **90.52%** |
| K-Nearest Neighbors | **89.23%** |

---

## Key Insights

- CIBIL Score is the most important feature for predicting loan approval.
- Loan Term has a weak negative correlation with the target.
- Most remaining features show weak linear correlation individually.
- Random Forest achieved the highest prediction accuracy.
