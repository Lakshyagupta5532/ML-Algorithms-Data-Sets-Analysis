# Titanic Survival Prediction

## Project Overview

This project predicts whether a passenger survived the Titanic disaster using Machine Learning. The project follows a complete machine learning workflow, including data cleaning, exploratory data analysis (EDA), preprocessing, feature engineering, model training, and model evaluation.

---

## Dataset

- Dataset: Titanic Dataset (Seaborn)
- Total Records: 891
- Target Variable: Survived

---

## Workflow

- Data Cleaning
- Handling Missing Values
- Removing Redundant Features
- Exploratory Data Analysis (EDA)
- Feature Encoding
- Feature Scaling
- Train-Test Split
- Machine Learning Model Training
- Model Evaluation

---

## Machine Learning Models Used

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- Gaussian Naive Bayes

---

## Key Insights

- Female passengers had a much higher survival rate than male passengers.
- Passengers in higher classes (Pclass 1) were more likely to survive.
- Younger passengers generally had better survival chances.
- Fare showed a positive relationship with survival.
- Passengers traveling alone had a comparatively lower survival rate.
